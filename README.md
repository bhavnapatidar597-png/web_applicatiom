# MediQueue – Clinic Appointment System

A web application to digitize clinic appointment booking, automate token generation, and manage patient queues in real time.

- **Problem:** Manual paper registers cause long wait times and administrative delays.
- **Solution:** Digital appointment scheduling with instant token assignment and live status updates.
- **Tech Stack:** HTML5, CSS3, JavaScript
